# scoop-autocorrect

Scoop bucket for [AutoCorrect for Windows](https://badatcoding12345678910.github.io/AutoCorrect-Windows/).

Package id is `autocorrect-windows` (avoids clashing with Scoop `main/autocorrect`, an unrelated CJK linter).

```powershell
scoop bucket add autocorrect https://github.com/BADATCODING12345678910/scoop-autocorrect
scoop install autocorrect/autocorrect-windows
```
